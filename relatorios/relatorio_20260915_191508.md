## Como foi calculado

1. **Total perdido**  
   ```sql
   SELECT SUM(price) AS total_lost_value
   FROM eventos
   WHERE event_type = 'cart'
     AND user_session NOT IN (
       SELECT user_session
       FROM eventos
       WHERE event_type = 'purchase'
     );
   ```

2. **Perda por categoria**  
   ```sql
   SELECT category_code, SUM(price) AS lost_value
   FROM eventos
   WHERE event_type = 'cart'
     AND user_session NOT IN (
       SELECT user_session
       FROM eventos
       WHERE event_type = 'purchase'
     )
   GROUP BY category_code
   ORDER BY lost_value DESC
   LIMIT 3;
   ```

- **`event_type = 'cart'`**: somente os itens que foram adicionados ao carrinho.  
- **`user_session NOT IN (...)`**: filtra apenas as sessões que *não* tiveram evento `purchase` (ou seja, carrinhos abandonados).  
- O `SUM(price)` acumula o valor de cada produto nessa sessão.
